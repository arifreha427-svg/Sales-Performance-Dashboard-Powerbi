# Sales Performance Dashboard

## Project Overview

This project presents an interactive Sales Performance Dashboard built using Power BI, SQL, DAX, and Excel.

The dashboard helps businesses monitor key sales metrics, analyze regional performance, track monthly growth, and identify top-performing products.

---

## Tools Used

- Power BI
- SQL
- DAX
- Excel Power Query

---

## Key Features

### KPI Monitoring
- Total Sales
- Total Profit
- Profit Margin
- Total Orders

### Sales Analysis
- Monthly Sales Trends
- Year-over-Year Growth
- Running Totals

### Regional Performance
- Sales by Region
- Regional Profitability

### Product Analysis
- Top Selling Products
- Category & Sub-Category Performance

### Dynamic Filtering
- Region
- Category
- Segment
- Year

---

## Data Preparation

- Cleaned raw sales data using Excel Power Query
- Performed SQL-based data transformations
- Built DAX measures for advanced analytics

---

## DAX Measures

- Total Sales
- Total Profit
- Profit Margin %
- Running Total Sales
- Previous Year Sales
- YoY Growth %
